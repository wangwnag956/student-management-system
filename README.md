# Student Task Management System

A web-based Student Task Management System developed across multiple practical iterations.

## Project Overview

This application helps students organise and manage their study tasks. Users can create tasks, edit task details, set deadlines and priorities, search for tasks, mark tasks as completed, and receive deadline reminders.

## Features

- Add a task
- Edit a task
- Delete a task
- Set a deadline
- Set task priority
- Search tasks
- Mark tasks as completed
- View tasks
- Deadline reminders
- Responsive layout for mobile-width screens

## Technology Stack

- HTML
- CSS
- JavaScript
- GitHub
- GitHub Pages
- Jest for unit testing
