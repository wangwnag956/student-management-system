# Student Management System

## Project Overview
This project is a simple web-based student management system developed for Practical 1.

## Objectives
- Manage student information
- Improve communication
- Store data securely

## Features
- Login
- Register
- Attendance
- Profile Management
- Announcements

## Technology Stack
- Frontend: HTML/CSS/JavaScript
- Backend: Node.js
- Database: MySQL
- Version Control: GitHub
