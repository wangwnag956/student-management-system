# TaskFlow – Student Task Management System

## Project Overview

TaskFlow is a simple web-based task management system designed for students.

It helps students create, organise, search, edit, complete, and manage their study tasks. Users can also register an account, log in securely, update their display name, and view task statistics.

## How to Use

1. Open the website and go to the registration page.
2. Create a new account using your name, email address, and password.
3. Log in using the registered email address and password.
4. Create a task by entering a task name, deadline, and priority.
5. Use the task buttons to:
   - Mark a task as completed
   - Edit a task
   - Delete a task
6. Use the search box to find tasks by task name.
7. View the dashboard to check total, completed, and remaining tasks.
8. Deleted tasks are moved to **Task History**.
9. In Task History, users can restore deleted tasks or permanently delete them.
10. Click **Settings** to update the display name.
11. Click **Log out** to leave the dashboard.
