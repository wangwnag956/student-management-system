# Initial Backlog Ideas

1. As a student, I want to log in so that I can access my account.

2. As a user, I want to register an account so that I can use the system.

3. As a student, I want to view my attendance so that I can track my progress.

4. As an admin, I want to manage student records so that data remains organized.

5. As a student, I want to update my profile so that my information stays accurate.

6. As a user, I want a simple interface so that the system is easy to use.

7. As a student, I want to receive announcements so that I get important updates.

8. As an admin, I want to generate reports so that I can monitor student activity.
